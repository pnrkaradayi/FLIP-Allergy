# FLIP-Allergy analysis (manuscript version)

Every number, table and figure of the manuscript is produced by the scripts below from the public
files in `../data_raw/` (see `../data_raw/README.md`). Figures and LaTeX tables are written to
`../../manuscript/figures` and `../../manuscript/tables`. Run from this folder:

```bash
cd flip_allergy/analysis
PY="python -I -W ignore"
$PY a00_prepare.py              # cohorts: D1 serum sIgE (7266), D2 NHANES III SPT (11,932), D3 dust
$PY a01_structure.py            # latent correlations, factor model, hidden-panel prediction, transport
$PY a02_risk_decision.py 20 10  # Task 1: FLIP vs Kim et al. etc., 20 MAR + 10 MNAR (~10 min, 10 cores)
$PY a02b_sensitivity.py         # Task 1: current asthma; missingness scale 0.5 / 1.5
$PY a02c_examples.py            # repetition-0 example files of the primary outcome (figures 4, 7)
$PY a03_atopy_testing.py        # Task 2: adaptive testing vs fixed panels, serum + skin prick
$PY a05_dust.py                 # dust block information
$PY a04_figures.py all          # figures 2-10 -> ../../manuscript/figures
$PY a06_tables.py               # LaTeX tables + results/numbers.json
$PY a07_supplement.py           # worked example, strata table, supplementary figures/tables
$PY diag_voi4.py                # linear vs censoring-aware preposterior (Spearman 0.77 vs 0.81)

# comparison with published studies on their own data
$PY a08_literature_nhanes.py    # Salo 2014, Gergen 2009, Zhu 2022, McGowan 2019, Hoppin 2011, Arbes 2005
$PY a09_external_flip.py        # Task 1 on MAAS, SOS-ALL, Graz, Moscow + 7 clinical datasets (~2 h, 10 cores)
$PY a10_external_testing.py     # Task 2 on Allergen Chip Challenge, MAAS, Guo, Moscow (~1 h)
$PY a11_external_reproduce.py   # published headline numbers; Graz culprit; heart deployment
$PY a12_external_figures.py     # figures 11-13, A6-A7 and the comparison tables
```

External data (downloaded once, read as data only): `../data_raw/external/` (UCI heart disease,
thyroid, hepatitis; OpenML Pima, chronic kidney disease, SUPPORT2; PhysioNet Challenge 2012 set A)
and `../data_raw/external_allergy/` (Allergen Chip Challenge, MAAS, Graz venom, SOS-ALL, Moscow
biochip, Chinese paediatric asthma). Download links are in `../data_raw/README.md`, loaders in
`ext_data.py`; the Gaussian-copula version of FLIP for mixed tables is `flipg.py`.

## Files

| File | Content |
|---|---|
| `flipx.py` | core library: censored multivariate normal (stochastic EM + Gibbs), cross-reactivity factor model, blocked Gibbs posterior completions, FLIP, isotonic calibration, Learn-then-Test (marginal, Mondrian), censoring-aware preposterior VOI |
| `results/numbers.json` | every number quoted in the text, generated by `a06_tables.py` |
| `results/*.csv` | per-repetition results of every analysis |

## Notes kept for transparency

* The cross-reactivity family set was refined once (peanut added to PR-10; pollen panallergen
  family) after inspecting calibration-split predictions; the prespecified set is reported too.
* The VOI estimator was changed from a linear to a censoring-aware preposterior after a
  diagnostic on the test split of repetition 0 (`diag_voi.py`, `diag_voi4.py`); the change is
  reported in the Methods.
* NHANES III: the wheal value 888 is a reserve code (test not performed) and is treated as
  missing (found when reproducing Arbes et al. 2005; cohort 10,841).
* External analyses: allergen panels use the cross-reactivity factor structure (ext_data.FAMILY_RULES,
  EXTRACT_FAMILIES); clinical tables a free covariance. SUPPORT and PhysioNet are capped at 3000
  training and 800 calibration/test records per repetition; the Allergen Chip Challenge uses one
  50/25/25 split, the other open cohorts rotating four-fold cross-fitting.
* Components that did not beat simple alternatives are reported in the Results/Limitations:
  per-patient panel choice vs Kim's static ranking; the certified-decisions budget objective;
  the Mondrian guarantee's coverage cost.
