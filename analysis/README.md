# Analysis scripts

Every number, table and figure of the manuscript is produced by the scripts below. Results are
written to `results/`, figures and LaTeX tables to `../outputs/`. Run from this folder, after the
data in `../data_raw/` are in place (see `../data_raw/README.md`):

```bash
python a00_prepare.py              # cohorts: D1 serum sIgE (7266), D2 NHANES III SPT (10,841), D3 dust
python a01_structure.py            # latent correlations, factor model, hidden-panel prediction, transport
python a02_risk_decision.py 20 10  # Task 1: FLIP vs Kim et al. etc., 20 MAR + 10 MNAR (~10 min, 10 cores)
python a02b_sensitivity.py         # Task 1: current asthma; missingness scale 0.5 / 1.5
python a02c_examples.py            # repetition-0 example files of the primary outcome
python a03_atopy_testing.py        # Task 2: adaptive testing vs fixed panels, serum + skin prick
python a05_dust.py                 # information carried by household dust allergens
python a04_figures.py all          # main figures
python a06_tables.py               # LaTeX tables + results/numbers.json
python a07_supplement.py           # worked example, strata table, supplementary figures/tables
python diag_voi4.py                # linear vs censoring-aware preposterior value of information

# comparison with published studies on their own data
python a08_literature_nhanes.py    # Salo 2014, Gergen 2009, Zhu 2022, McGowan 2019, Hoppin 2011, Arbes 2005
python a13_literature_assoc.py     # Salo 2011, Shargorodsky 2015 (association models refitted with FLIP)
python a15_visness.py              # Visness 2009
python a16_nhanes_more.py          # Arbes 2013, Keet 2012 (and the non-reproducible Busse 2013 check)
python a09_external_flip.py        # Task 1 on MAAS, SOS-ALL, Graz, Moscow, IDEAL + 7 clinical datasets (~2 h)
python a10_external_testing.py acc maas guo moscow ureca60 ureca120 eat36 leap60   # Task 2 (~1 h)
python a11_external_reproduce.py   # published headline numbers; Graz culprit; heart deployment
python a14_added_reproduce.py      # Bern, IDEAL, URECA, EAT, LEAP headline numbers
python a12_external_figures.py     # comparison figures and tables
python a17_main_tables.py          # compact comparison tables of the main text (certified decisions,
                                   # posterior decisions, test ordering, tests per study, associations,
                                   # prediction of unordered tests)
```

## Files

| File | Content |
|---|---|
| `flipx.py` | core library: censored multivariate normal (stochastic EM + Gibbs), cross-reactivity factor model, posterior completions, FLIP score, isotonic calibration, Learn-then-Test (marginal, Mondrian), censoring-aware preposterior value of information |
| `flipg.py` | Gaussian-copula version of FLIP for mixed tables (assays, binary and continuous findings) |
| `ext_data.py` | loaders, sources and cross-reactivity families of the external datasets |
| `a03_atopy_testing.py` | adaptive testing with a certified miss rate, fixed panels (greedy set cover), sequential testing |
| `results/numbers.json` | every number quoted in the text (generated by `a06_tables.py`) |

## Notes kept for transparency

* The cross-reactivity family set was refined once (peanut added to PR-10; pollen panallergen
  family) after inspecting calibration-split predictions; the prespecified set is reported too.
* The value-of-information estimator was changed from a linear to a censoring-aware preposterior
  after a diagnostic on the test split of repetition 0 (`diag_voi*.py`); the change is reported in
  the Methods.
* NHANES III: the wheal value 888 is a reserve code (test not performed) and is treated as missing
  (found when reproducing Arbes et al. 2005).
* External analyses: allergen panels use the cross-reactivity factor structure
  (`ext_data.FAMILY_RULES`, `EXTRACT_FAMILIES`); clinical tables a free covariance. SUPPORT and
  PhysioNet are capped at 3000 training and 800 calibration/test records per repetition; the
  Allergen Chip Challenge uses one 50/25/25 split, the other cohorts rotating four-fold cross-fitting.
* Results in which FLIP did not beat simple alternatives are reported in the paper, e.g. the tie
  with multiple imputation in SOS-ALL and IDEAL, and the EAT skin test panel, where the model
  without cross-reactivity needed slightly fewer tests.
